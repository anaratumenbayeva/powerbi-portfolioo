Репозиторий содержит проекты по разработке интерактивных отчётов, моделированию данных, визуализации KPI и бизнес-аналитике в Power BI.

## 1. Аналитика продаж и финансовые показатели

**Файл проекта:** `sales-analytics.pbix`

### Описание задачи
Цель проекта — разработка интерактивного дашборда для комплексного мониторинга финансовых показателей продаж, оценки рентабельности, контроля затрат на логистику и выявления убыточных операций в разрезе менеджеров, номенклатуры и сегментов клиентов.

### Архитектура и модель данных
* **Стек:** Power BI, Power Query, DAX
* **Модель данных:** Схема «Звезда» (Star Schema)
  * Таблица фактов: `Продажи`
  * Таблицы измерений: `СПР_Менеджеры`, `СПР_Покупатели`, `СПР_Продукты`, `СПР_стоимость_доставки`, `СПР_даты_заказа`, `Calendar`

### Метрики и функционал
* **Ключевые KPI:** Выручка (1.10 млн), Прибыль (253.78 тыс.), Средний чек (173), Рентабельность (23.13%), Затраты на логистику (4.41 тыс.).
* **ABC-анализ:** Группировка категорий по выручке и затратам на доставку.
* **Анализ убыточности:** Отдельный блок с детализацией заказов с отрицательной прибылью (общий убыток: -51 685.36).

### Выводы по данным
1. Наибольшую выручку генерирует категория *Telephones and Communication* (0.26 млн).
2. Выявлена проблема с отрицательной маржой по заказам менеджеров Мерингольд В. и Семейкина В., что требует пересмотра скидочной политики.

## 2. Комплексный аналитический отчёт: Продажи, Логистика и Персонал

**Файл проекта:** `sales-performance-analytics.pbix`

### Описание задачи
Разработка многостраничного отчёта для полного аудита операционной деятельности компании. Проект объединяет аналитику выручки, складских запасов, географии клиентов и производительности сотрудников для поиска точек убыточности и оптимизации процессов.

### Архитектура и модель данных
* **Стек:** Power BI, Power Query, DAX
* **Модель данных:** Развернутая схема с отдельными таблицами фактов и справочников (`Calendar`, `Student public_clients`, `Student public_orders`, `Student public_stocks`, `Student public_staff` и др.).

### Структура отчёта и ключевые метрики
1. **Продажи и прибыль:**
   * **KPI:** Total Sales (227.19 млн), Profit (184.19 млн), Profit Margin % (81.07%).
   * Анализ динамики продаж по месяцам и маржинальности по категориям (*Home Appliances, Clothing, Electronics* — лидеры с маржой ~81%).
2. **Логистика и склады:**
   * Оценка остатков товаров по складам (*Warehouse_1, Warehouse_10, Warehouse_2* и др.) и способов доставки (*Pickup, Standard, Courier Delivery, Express*).
   * Доля затрат на логистику (Shipping Cost %: 0.02%).
3. **Клиенты и регионы:**
   * Географическое распределение продаж по регионам на интерактивной карте.
   * Оценка метрик: Средний чек (Average Order Value: 113.54 тыс.), количество клиентов (201) и анализ доли возвратов (Returns Rate %).
4. **Сотрудники и эффективность:**
   * Анализ штата (101 сотрудник) и фонда оплаты труда (Сумма salary: 34.14 млн).
   * Расчет выработки на человека (Revenue per Employee: 2.95 млн) и распределение ролей по складам.

### Ключевые выводы и рекомендации
* **Ассортимент:** Зафиксировано падение продаж в 2024–2025 гг. Рекомендуется перераспределить рекламный бюджет в пользу высокомаржинальных категорий (*Home Appliances, Electronics*).
* **Логистика:** Выявлен дисбаланс остатков: склады *Warehouse_1* и *Warehouse_10* перегружены, тогда как наибольшую выручку генерируют *Warehouse_9* и *Warehouse_4*.
* **HR & Эффективность:** Требуется пересмотр численности персонала на складах с низкой выручкой для выравнивания показателя *Revenue per Employee*.

## 3. Операционный отчёт по продажам и ABC-анализ товаров

**Файл проекта:** `supply-chain-analysis.pbix`

### Описание задачи
Создание двухстраничного дашборда для отслеживания динамики продаж по складам за период (Январь — Август 2018 г.) и проведения классификации товарных позиций (ABC-анализ) для оптимизации управления товарными запасами.

### Архитектура и модель данных
* **Стек:** Power BI, Power Query, DAX
* **Модель данных:** Оптимизированная структура с основной таблицей фактов `data` и сводной таблицей ABC-классификации `ABC`.

### Метрики и функционал
* **Операционные KPI:** Количество продаж (889.47 тыс.), Количество товаров (24), Количество клиентов (211), Уникальные дни продаж (205).
* **Страница «Отчёт по складам»:** 
  * Навигационная панель с быстрым переключением между отчётами.
  * Мульти-срезы по номенклатуре, контрагентам и диапазону дат.
  * График «Динамика продаж по ведущим трём складам» для отслеживания сезонности и дневных пиков нагрузок.
* **Страница «ABC-анализ»:**
  * Таблица классификации товаров с отнесением к группам A, B и C на основе суммарного объёма продаж.
  * Анализ категорий: Группа A формирует 69.58% объема, Группа B — 25.17%.
  * Круговая диаграмма распределения долей категорий в общем объёме.

### Ключевые выводы
1. **Концентрация продаж:** Около 70% всего объёма продаж обеспечивается ограниченной группой товаров категории A (*product_0, product_1, product_19*).
2. **Товарная матрица:** Товары категории C требуют пересмотра условий хранения или исключения из матрицы для высвобождения оборотных средств.
